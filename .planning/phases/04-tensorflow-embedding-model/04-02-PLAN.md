## Objective

Create `train_action_predictor_embedding.py` — a TensorFlow-only training script that uses the Keras Functional API with entity embedding layers for categorical inputs instead of one-hot encoding. Must import shared helpers from `feature_engineering.py`. Target: val_accuracy > 30%.

## Architecture Design

```
Inputs (dict-based):
  "species_p1"   → Embedding(species_vocab, 48) → Flatten
  "species_p2"   → Embedding(species_vocab, 48) → Flatten  [shared weights optional, separate safer]
  "last_move_p1" → Embedding(move_vocab, 32)    → Flatten
  "last_move_p2" → Embedding(move_vocab, 32)    → Flatten
  "status_p1"    → Embedding(status_vocab, 8)   → Flatten
  "status_p2"    → Embedding(status_vocab, 8)   → Flatten
  "tera_type_p1" → Embedding(type_vocab, 8)     → Flatten
  "tera_type_p2" → Embedding(type_vocab, 8)     → Flatten
  "numerical"    → Dense branch (no embed)
  "revealed_moves_p1" → Dense(32, use_bias=False)   [sum-pool of multi-hot]
  "revealed_moves_p2" → Dense(32, use_bias=False)   [sum-pool of multi-hot]
  
All concat → Dense(512, swish) → BN → Dropout(0.25)
           → Dense(256, swish) → BN → Dropout(0.25)
           → Dense(128, swish) → BN → Dropout(0.2)
           → Dense(num_classes, softmax)
```


Embedding dimensions:
- Species vocab → `dim=48`, `embeddings_regularizer=keras.regularizers.l2(1e-5)`
- Move vocab → `dim=32`
- Status vocab → `dim=8`
- Type vocab → `dim=8`
- Bench slot species → `dim=24` (smaller — just identity context)

After each Embedding: `layers.Flatten()`

Revealed moves branches:
```python
revealed_p1 = layers.Dense(32, use_bias=False, name='move_pool_p1')(revealed_p1_in)
revealed_p2 = layers.Dense(32, use_bias=False, name='move_pool_p2')(revealed_p2_in)
```

Concatenate all branches, then:
```python
x = layers.Concatenate()([all_embed_outputs + [numerical_branch, revealed_p1, revealed_p2]])
x = layers.Dense(512, use_bias=False)(x)
x = layers.BatchNormalization()(x)
x = layers.Activation('swish')(x)
x = layers.Dropout(0.25)(x)
x = layers.Dense(256, use_bias=False)(x)
x = layers.BatchNormalization()(x)
x = layers.Activation('swish')(x)
x = layers.Dropout(0.25)(x)
x = layers.Dense(128, use_bias=False)(x)
```
